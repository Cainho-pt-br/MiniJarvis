Internet lenta ou caiu? Como saber de quem é a culpa

Um teste de um minuto para descobrir se o problema é o Wi-Fi, o roteador, o provedor ou o próprio computador.

O teste de um minuto

  1. Outro aparelho: o celular no mesmo Wi-Fi também está lento? Se sim, o problema não é o computador.
  2. Perto do roteador: vá até ele. Melhorou? É alcance do Wi-Fi (paredes, distância, micro-ondas).
  3. Reinicie o roteador: tire da tomada, conte 30 segundos, ligue. Resolve metade dos casos.
  4. Ping: no Windows, abra o Prompt de Comando e digite ping 1.1.1.1. "Esgotado o tempo limite" significa que a internet caiu de verdade; tempos acima de 100 ms indicam rede ruim.
  5. Ainda ruim no cabo? Então é o provedor: ligue para ele com o resultado do ping na mão.

Se só o computador está lento

Veja se alguma atualização ou programa está baixando algo (Windows Update, jogos, nuvem sincronizando). No Gerenciador de Tarefas, a coluna Rede mostra quem está usando a conexão.
