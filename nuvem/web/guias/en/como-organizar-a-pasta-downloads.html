How to organize your Downloads folder once and for all

A 10-minute method to stop your Downloads folder from becoming a dumping ground, and how to keep it clean effortlessly.

Why the Downloads folder becomes a dumping ground

Everything you download lands there: invoices, photos, installers, work PDFs. Because there is never a good time to tidy up, it piles up. The good news: organizing by file type solves 90% of the mess without having to make decisions.

The method

  1. Open Downloads and sort by Type (click the column header).
  2. Create these folders: Images, Documents, Videos, Archives, Installers.
  3. Select each group of files of the same type and drag them into the right folder. Installers (.exe, .dmg, .msi) for programs you already installed can go straight to the trash.
  4. Sort by Size and check the 15 largest files: old videos and archives often free up gigabytes.

How to keep it clean

Once a week, repeat step 3. It takes two minutes. Or let someone do it for you: Jarvis has the ready-made action Organize Downloads, which moves loose files into those folders without deleting anything, and Largest files in Downloads, which shows what is worth deleting.
